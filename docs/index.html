Why plain HTML?

Because a landing page should be the easiest part of your launch.

  • Fast by default

    Each template is under 30 KB — less than 10 KB compressed. No scripts to download, parse or break.

  • Private

    No trackers, no web fonts, no CDNs. Nothing loads from anyone else's server unless you add it.

  • Free to host

    Publish on GitHub Pages, Netlify or Cloudflare Pages in minutes. Step-by-step guide included.

  • Re-theme in one place

    Colours, fonts and corners are CSS variables at the top of one file. Change the accent colours and you're most of the way there.

  • Accessible

    Semantic HTML, skip links, visible keyboard focus, AA contrast and reduced-motion support.

  • Built to last

    No dependencies means no updates to chase. It'll open the same way in ten years.

Frequently asked questions

Do I need to know how to code?

You need to be comfortable opening an HTML file in a text editor and changing the words between the tags. The included guide walks through everything else — colours, images, forms and publishing — step by step.

Can I use the templates for client projects?

Yes. The licence covers unlimited websites for yourself and for clients, including paid client work.

Can I resell the templates?

No. You can sell websites you build with Plainpage, but not the templates themselves, in original or modified form.

How do I publish my page?

Upload the two files to any static host. The guide covers Netlify Drop (drag and drop your folder), GitHub Pages and Cloudflare Pages — all with free plans.

Does it work with WordPress, Webflow or Squarespace?

Not directly. Plainpage is plain HTML and CSS, meant to be hosted as-is. If you need a WordPress theme or a visual builder, this isn't the right product.

Which browsers are supported?

Current versions of Chrome, Edge, Firefox and Safari on desktop and mobile.
